# 🛠️ Doc-Forge: Универсальный двусторонний компилятор и инспектор документов (ГОСТ / СТО)

Комплекс для **двусторонней конвертации**, **реверс-инжиниринга макетов** и **детерминированной компиляции** академических и корпоративных документов (курсовые, дипломы, отчеты) в строгом соответствии с требованиями нормоконтроля (**ГОСТ 7.32-2017**, **ГОСТ 2.105-2019**, **СТО СаМеК**, **СТО СамГТУ**).

---

## 🚀 Ключевые возможности

### 1. 📥 Прямой ход: Любые документы $\to$ Rich Markdown + YAML-профиль + Отчет о макете
- **Поддерживаемые форматы:** `DOCX`, `PDF`, `XLSX`, `PPTX`, `RTF`, `EPUB`, `CSV`, `TSV`.
- **Семантический парсинг:** Извлечение иерархии заголовков (`H1`–`H3`), списков, таблиц (GFM), формул, блоков кода и заметок слайдов.
- **Реверс-инжиниринг геометрии и типографики:** Вычисление точных полей (мм), доминирующих шрифтов, кеглей (pt), межстрочных интервалов, красной строки (см), выравнивания и интервалов абзацев.
- **Парсинг титульных листов:** Автоматическое распознавание министерства, учебного заведения, кафедры, специальности, темы, типа работы, года и 2-колоночной сетки подписей (студент / руководитель) в структурированный YAML Frontmatter.

### 2. 📤 Обратный ход: Rich Markdown + Профиль $\to$ DOCX / PDF
- **Иммунитет к ошибкам LLM:** Полная защита от паразитных пустых строк (`\n\n`), срывов таблиц и плавающих подписей.
- **Защита от висячих заголовков:** Принудительное включение `w:keepNext` для заголовков и `w:widowControl` для абзацев.
- **Сетка титульного листа:** Изолированный первый раздел (`Section 1`) без нумерации и колонтитулов с точным вертикальным распределением.
- **Нативное оглавление:** Генерация страницы «СОДЕРЖАНИЕ» с табуляцией по правому краю и точками-отточиями (`WD_TAB_LEADER.DOTS`).
- **Сетка таблиц:** Повтор шапки на каждой новой странице (`w:tblHeader`), тонкие границы 0.5 pt, внутренние поля ячеек (`tcMar`).
- **Экспорт в PDF:** Автоматическая компиляция в PDF через headless LibreOffice.

## 💻 Команды CLI

### 1. Прямая конвертация любого документа в Markdown
```bash
# Конвертация DOCX / PDF / XLSX / PPTX / RTF / EPUB / CSV
python3 src/cli.py convert sample.pdf -o sample.md -p profiles/extracted_profile.yaml

# Быстрая конвертация таблицы Excel или презентации PowerPoint
python3 src/cli.py convert data.xlsx -o data.md
python3 src/cli.py convert presentation.pptx -o presentation.md
```

### 2. Глубокая инспекция и реверс-инжиниринг макета (DOCX, PDF)
```bash
# Извлечение точных метрик оформления чужого образца в профиль YAML
python3 src/cli.py inspect obrazets.docx -o profiles/new_uni.yaml
```

### 3. Компиляция Markdown в DOCX / PDF по профилю ГОСТ
```bash
# Сборка документа DOCX
python3 src/cli.py build work.md -p samek -o work.docx

# Сборка документа DOCX + мгновенный экспорт в PDF
python3 src/cli.py build work.md -p samek -o work.docx --pdf
```

### 4. Генерация эталонного 4-страничного теста нормоконтроля
```bash
python3 src/cli.py test samek --pdf
```

### 5. Управление профилями оформления
```bash
# Список всех профилей
python3 src/cli.py list

# Просмотр детальных параметров
python3 src/cli.py show samek

# Точечное изменение параметра (например, кегль или левое поле)
python3 src/cli.py set samek body.font_size_pt 14.0
python3 src/cli.py set samek page.margins.left_mm 30.0
```

## 📂 Архитектура проекта

- `src/converters/` — Модули прямой конвертации:
  - `docx_engine.py` — OpenXML инспектор, извлечение титульника, таблиц и типографики.
  - `pdf_engine.py` — Анализ пространственной геометрии, шрифтовая гистограмма, таблицы (PyMuPDF / pdfplumber).
  - `xlsx_engine.py` — Конвертер таблиц Excel с сохранением листов и формул.
  - `pptx_engine.py` — Слайд-за-слайдом конвертер презентаций с заметками спикера.
  - `rtf_engine.py`, `epub_engine.py`, `csv_engine.py` — Специализированные парсеры форматов.
  - `router.py` — Универсальный диспетчер форматов.
- `src/schema.py` — Pydantic v2 схемы валидации профилей оформления.
- `src/title_engine.py` — Генератор титульного листа без нумерации с сеткой подписей.
- `src/toc_engine.py` — Построитель оглавления с точками-отточиями.
- `src/compiler.py` — Детерминированный транслятор Markdown $\to$ DOCX.
- `src/inspector.py` — Реверс-инжиниринг макетов в YAML-профили.
- `src/cli.py` — Интерфейс командной строки (Typer + Rich).
- `profiles/` — Готовые декларативные профили (`samek.yaml`, `gost_7_32.yaml`, `samgtu.yaml`).
- `test_samples/` — Эталонные сэмплы документов.
