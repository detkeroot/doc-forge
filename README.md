# 🛠️ Doc-Forge: Декларативный компилятор и инспектор академических документов (ГОСТ / СТО)

Комплекс для автоматизированной подготовки, инспекции и компиляции курсовых и дипломных проектов в формат Microsoft Word (.docx) в строгом соответствии с требованиями нормоконтроля (ГОСТ 7.32-2017, ГОСТ 2.105-2019, СТО СаМеК, СТО СамГТУ).

---

## 🚀 Возможности
- **Защита от сбоев верстки:** Ликвидация пустых абзацев (`\n\n`), запрет отрыва заголовков от текста (`keep_with_next`), повтор шапок таблиц на новых листах (`tblHeader`).
- **Сетка титульных листов:** Первый раздел (Section 1) без нумерации, скрытая 2-колоночная таблица реквизитов (студент/руководитель).
- **Нативное оглавление:** Страница «СОДЕРЖАНИЕ» с табуляцией по правому краю и точками-отточиями.
- **Реверс-инжиниринг DOCX:** Команда `inspect` парсит OpenXML (`document.xml`, `styles.xml`) образца и генерирует YAML-профиль.
- **Интерактивное редактирование:** YAML-профили легко правятся как вручную, так и в диалоге с AI-агентом.

## 📦 Быстрый старт

### 1. Запуск через Nix (Flakes / DevShell)
```bash
cd /home/detker/Документы/repository/doc-forge
nix develop
# или: nix-shell
```

### 2. Основные команды CLI:

```bash
# Список доступных профилей
python3 src/cli.py list

# Генерация эталонного 4-страничного тестового документа (СаМеК)
python3 src/cli.py test samek -o test_samek_4page.docx

# Компиляция своего Markdown документа
python3 src/cli.py build work.md -p samek -o work.docx

# Реверс-инжиниринг чужого образца в профиль YAML
python3 src/cli.py inspect sample.docx -o profiles/new_uni.yaml

# Точечное изменение параметра профиля
python3 src/cli.py set samek body.font_size_pt 14.0
```

## 📂 Структура проекта
- `src/schema.py` — Pydantic-схемы валидации профилей.
- `src/title_engine.py` — Генератор титульного листа.
- `src/toc_engine.py` — Построитель оглавления с отточиями.
- `src/compiler.py` — AST-транслятор Markdown в DOCX.
- `src/inspector.py` — Реверс-инжиниринг параметров из DOCX.
- `src/cli.py` — Интерфейс командной строки (Typer + Rich).
- `profiles/` — Готовые профили (`samek.yaml`, `gost_7_32.yaml`, `samgtu.yaml`).
- `test_samples/` — Эталонный Markdown с Frontmatter.
